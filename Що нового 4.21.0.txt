PRICE MONITOR 4.21.0 — ЧОТИРИ ПОКРАЩЕННЯ В ОДНОМУ РЕЛІЗІ

1. Віддалений клієнт через сервер власника

• Панель власника й клієнтський API тепер працюють на різних портах.
• Панель керування доступна лише на комп’ютері власника: 127.0.0.1:8787.
• Для клієнтів відкривається тільки обмежений API на порту 8788.
• Публічний порт не віддає адмінку, токен адміністратора або приватний ключ.
• Тестовий клієнт підготовлений для адреси 188.163.88.129:45873.

Увага: адреса запрацює з іншої мережі лише після ручного налаштування переадресації порту на роутері та правила брандмауера. У цьому релізі ці системні налаштування навмисно не змінювалися.

2. Активація з підтвердженням і живе керування

• Нова ліцензія за замовчуванням має статус «Очікує підтвердження».
• Клієнт вводить код, програма прив’язує запит до конкретного пристрою, але пошук ще заблокований.
• Власник бачить пристрій у панелі та може підтвердити, призупинити або заблокувати ліцензію.
• У тестовій збірці клієнт перевіряє рішення кожні 5 секунд.
• Зміна доступних магазинів також доходить до клієнта автоматично.
• Якщо сервер тимчасово недоступний, уже оплачений клієнт працює до кінця підписаного автономного допуску.

3. Серверні оновлення

• Власник може обрати готовий EXE-інсталятор у панелі, задати версію, канал і опис.
• Сервер копіює файл, рахує SHA-256 та підписує маніфест приватним ключем.
• Клієнт приймає лише оновлення з правильною цифровою підписом і точною контрольною сумою.
• Оновлення не встановлюється мовчки: програма показує версію й опис, користувач сам натискає кнопку встановлення.
• Адмінка підтримує канали оновлень, тому надалі можна розвести тестові та стабільні версії.

4. Telegram-сповіщення

• У панель додано необов’язкові налаштування Telegram-бота.
• Є кнопка тестового повідомлення.
• Підготовлені повідомлення про новий пристрій, зміну статусу та завершення оплати через 7 днів, завтра або сьогодні.
• Повторне однакове нагадування не надсилається.
• Пошукові запити й назви торгових марок у Telegram не передаються.

ПЕРЕВІРКИ

• 108 автоматичних тестів пройдено.
• Перевірено сценарій «очікує → власник підтвердив → клієнт працює».
• Перевірено, що публічний порт не відкриває панель власника.
• Перевірено підписаний маніфест, точне завантаження EXE та відмову від підроблених даних.
• Повна, демо й попередня офлайн-ліцензійна версії мають окремі профілі та цим релізом не замінюються.

ЩО ЩЕ НЕ Є ГОТОВИМ ПРОДАКШЕНОМ

• Зовнішній доступ через роутер ще не ввімкнено.
• Пряма HTTP-адреса потрібна лише для домашнього експерименту; для продажів потрібен HTTPS у хмарі.
• Telegram не працюватиме, доки власник сам не введе токен бота і Chat ID.
• Для реальної перевірки оновлення треба опублікувати клієнтську версію, новішу за встановлену.
