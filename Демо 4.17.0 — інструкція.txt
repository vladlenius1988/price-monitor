ІНСТРУКЦІЯ — ДЕМО Price Monitor 4.17.0

Цей файл пояснює лише встановлення програми. Інструкція з роботи, обмеження демо та вирішення проблем знаходяться всередині вже встановленої програми: кнопка «Інструкція».

## Встановлення

1. Запустіть файл `Price Monitor Demo Setup 4.17.0.exe`.
2. Дочекайтеся завершення встановлення.
3. Залиште запропоновану окрему папку з назвою `Price Monitor Demo`.
4. Не встановлюйте демо в папку повної версії Price Monitor.

Демо та повна версія можуть бути встановлені на одному комп’ютері. Вони зберігають свої дані окремо.

## Якщо Windows попереджає про безпеку

Windows може показати вікно «Windows захистила ваш комп’ютер» або повідомлення, що видавець програми невідомий. Якщо файл отримано з надійного джерела:

1. Натисніть `Докладніше`.
2. Натисніть `Виконати все одно`.
3. Якщо Windows попросить дозвіл адміністратора, підтвердьте його.

Це попередження репутації файлу Windows, а не помилка парсера. Якщо замість цього антивірус повністю видалив файл, отримайте інсталятор повторно та не запускайте випадкові копії з інших джерел.

## Перший запуск

- Запустіть Price Monitor Demo через ярлик у меню «Пуск» або на робочому столі.
- Для роботи не потрібна певна версія Chrome чи Edge: програма має власний браузерний рушій.
- Подальші пояснення шукайте всередині програми в розділі «Інструкція».

## Оновлення або видалення

- Нову демо-версію встановлюйте в ту саму папку `Price Monitor Demo`.
- Повну версію та демо не встановлюйте в один каталог.
- Видалення програми через Windows не повинно змішувати дані повної версії та демо.
