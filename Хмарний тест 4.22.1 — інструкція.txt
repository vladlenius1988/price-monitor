PRICE MONITOR CLOUD TEST 4.22.1 — КОРОТКА ІНСТРУКЦІЯ

У КОМПЛЕКТІ

1. Price Monitor Cloud Admin Setup 4.22.1.exe — приватна панель власника.
2. Price Monitor Cloud Test Setup 4.22.1.exe — клієнт для іншого комп'ютера.

Не плутайте Cloud Test зі старим Price Monitor Remote Test. Remote Test
звертався до домашнього IP і більше не потрібен для перевірки Cloudflare.

ПЕРЕВІРКА

1. Відкрийте Price Monitor Cloud Admin на комп'ютері власника.
2. Створіть тестову ліцензію та скопіюйте одноразовий код активації.
3. Встановіть Price Monitor Cloud Test на іншому комп'ютері.
4. Натисніть перевірку сервера. До активації програма повинна написати:
   «Сервер доступний. Для першого запуску введіть код активації».
5. Введіть код, активуйте комп'ютер і, якщо ліцензія очікує підтвердження,
   підтвердьте її в Cloud Admin.

ПРЯМА ПЕРЕВІРКА СЕРВЕРА

Відкрийте у браузері:
https://price-monitor-license-staging.vladlenius.workers.dev/health

Справний сервер відповідає JSON з "ok":true.

ВАЖЛИВО

- Cloud Admin не надсилайте клієнтам.
- Повна версія, демо й Cloud Test мають окремі каталоги та дані.
- Це staging-середовище для тестування, а не бойові продажі.
- Якщо браузер відкриває /health, але програма не активується, передайте
  точний текст повідомлення, час спроби та скриншот.
