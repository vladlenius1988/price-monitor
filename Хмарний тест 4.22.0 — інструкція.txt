PRICE MONITOR CLOUD TEST 4.22.0 — ІНСТРУКЦІЯ

Це окремий тестовий комплект для перевірки хмарних ліцензій через Cloudflare.
Повна версія, демо та їхні дані не змінюються.

У КОМПЛЕКТІ

1. Price Monitor Cloud Admin Setup 4.22.0.exe — приватна панель власника.
2. Price Monitor Cloud Test Setup 4.22.0.exe — окремий клієнт для тестового комп'ютера.

ВАЖЛИВО

- Адмінський інсталятор призначений лише власнику. Не пересилайте його клієнтам.
- Панель власника на цьому комп'ютері автоматично використовує раніше створений локальний ключ керування.
- Клієнт не містить приватного ключа або адмінського токена.
- Сервер працює у тестовому середовищі staging. Реальні продажі через цю збірку поки не проводяться.

ПЕРЕВІРКА АКТИВАЦІЇ

1. На комп'ютері власника встановіть і відкрийте «Price Monitor Cloud Admin».
2. Переконайтеся, що зверху написано «Хмарний сервер працює».
3. У блоці «Нова ліцензія» вкажіть тестового клієнта, дату, кількість комп'ютерів і магазини.
4. Для повного сценарію залиште початковий стан «Очікує підтвердження».
5. Натисніть «Створити й видати код». Код показується лише один раз і копіюється в буфер обміну.
6. На іншому комп'ютері встановіть «Price Monitor Cloud Test».
7. Вставте код у поле активації та натисніть «Активувати».
8. Клієнт повідомить, що очікує підтвердження. У панелі власника натисніть «Оновити дані».
9. Біля нової ліцензії натисніть «Підтвердити».
10. Тестовий клієнт перевіряє статус кожні 5 секунд і має автоматично відкрити доступ.

ЩО ЩЕ ПЕРЕВІРИТИ

- Змініть дозволені магазини та збережіть правила — клієнт має отримати новий набір.
- Натисніть «Призупинити» — клієнт має заблокувати пошук під час наступної перевірки.
- Поверніть статус «Активна» — доступ має відновитися.
- Відв'яжіть тестовий пристрій — він перестане займати місце ліцензії.
- Перезапустіть обидві програми та переконайтеся, що стан зберігся у хмарній базі.

ВІДОМИЙ ОБСЯГ ЦЬОГО РЕЛІЗУ

- Працюють: створення ліцензій, активація, підтвердження, продовження, блокування, магазини, ліміт пристроїв і журнал подій.
- Хмарне розповсюдження оновлень і Telegram-сповіщення ще не підключені, тому ці блоки в хмарній адмінці приховані.
- Інтервал 5 секунд увімкнено лише для швидкого тесту. У комерційному клієнті він буде значно довшим.

ЯКЩО ЩОСЬ НЕ ПРАЦЮЄ

1. Не видаляйте повну версію, демо, ліцензійні файли або дані програм.
2. Запишіть точний текст помилки.
3. Перевірте адресу сервера у браузері:
   https://price-monitor-license-staging.vladlenius.workers.dev/health
4. Якщо відповідь містить "ok":true, сервер доступний.
5. Зробіть скриншот і передайте розробнику разом з описом кроків.
