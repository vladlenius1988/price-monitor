PRICE MONITOR 4.27.0 — КОРОТКА ІНСТРУКЦІЯ

ФАЙЛИ

1. Price Monitor Online Setup 4.27.0.exe — програма клієнта.
2. Price Monitor Owner Setup 4.27.0.exe — панель власника.

ОНОВЛЕННЯ КЛІЄНТА

1. Закрийте Price Monitor Online.
2. Запустіть Price Monitor Online Setup 4.27.0.exe.
3. Встановіть поверх попередньої Online-версії.
4. Активація, архіви, списки й налаштування залишаться на місці.

ОНОВЛЕННЯ ВЛАСНИКА

1. Закрийте Price Monitor Owner.
2. Запустіть Price Monitor Owner Setup 4.27.0.exe.
3. Встановіть поверх попередньої Owner-версії.
4. Відкрийте розділ «Звернення підтримки».

ЯК КЛІЄНТ ПОВІДОМЛЯЄ ПРО ПРОБЛЕМУ

1. Після помилки натискає «Надіслати діагностику».
2. Отримує номер звернення.
3. Власник бачить звернення в Owner без пересилання файлів і без доступу до комп'ютера клієнта.
4. Якщо сервер тимчасово недоступний, клієнт натискає «Зберегти діагностику» та передає JSON вручну.

Windows може показати попередження через відсутність платного цифрового підпису. Для файла, отриманого безпосередньо від власника Price Monitor, натисніть «Докладніше» → «Виконати в будь-якому разі».

ВАЖЛИВО

- Діагностика не містить запитів, брендів, товарів, цін або штрихкодів.
- Telegram-сповіщення поки не активовані: для них окремо потрібні Bot token і Chat ID.
