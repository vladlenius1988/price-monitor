PRICE MONITOR SERVER 4.21.0 — ІНСТРУКЦІЯ ВЛАСНИКА

ЩО ВСТАНОВЛЮВАТИ

На комп’ютері власника встановіть тільки:
Price Monitor Server Setup 4.21.0.exe

Не передавайте цей файл клієнтам. У серверній збірці є приватний ключ, яким підписуються ліцензії та оновлення.

ЩО ВІДБУВАЄТЬСЯ ПІСЛЯ ЗАПУСКУ

• Відкривається локальна панель власника.
• Панель: 127.0.0.1:8787 — лише для цього комп’ютера.
• Клієнтський API: порт 8788 — без адмінки.
• Дані зберігаються у профілі Windows «Price Monitor Server».
• Коли серверна програма закрита, віддалені перевірки не працюють.

ЯК ВИДАТИ ТЕСТОВИЙ ДОСТУП

1. У блоці «Нова ліцензія» введіть клієнта, дату, кількість комп’ютерів і магазини.
2. Залиште стан «Очікує підтвердження».
3. Натисніть «Створити й видати код».
4. Скопіюйте код: повністю він показується лише під час створення.
5. Клієнт вводить код у своїй програмі.
6. У панелі з’явиться його пристрій.
7. Натисніть «Підтвердити». Тестовий віддалений клієнт побачить рішення приблизно за 5 секунд.

Стани:
• Очікує підтвердження — пристрій відомий, пошук заборонено.
• Активна — пошук дозволено в обраних магазинах.
• Призупинена — тимчасовий блок.
• Заблокована — відкликання доступу.

ЯК ОПУБЛІКУВАТИ ОНОВЛЕННЯ

Для першого наскрізного тесту в комплекті вже є контрольний файл «Price Monitor Remote Test Setup 4.21.1.exe». У ньому немає окремих функціональних змін: він потрібен лише для перевірки механізму оновлення з версії 4.21.0.

1. У блоці «Оновлення клієнтів» вкажіть версію 4.21.1.
3. Канал для поточного тестового клієнта: licensed.
4. Натисніть «Обрати файл» і виберіть контрольний EXE 4.21.1 з комплекту.
5. Додайте короткий опис і натисніть «Опублікувати оновлення».
6. Клієнт побачить повідомлення автоматично або після кнопки «Перевірити оновлення».

Однакова або старіша версія навмисно не пропонується.

TELEGRAM

1. Уведіть Bot token і Chat ID.
2. Увімкніть сповіщення та збережіть.
3. Натисніть «Надіслати тест».

Токен зберігається лише на серверному комп’ютері й не повертається в інтерфейс після збереження.

ЗОВНІШНІЙ ТЕСТ ЧЕРЕЗ МОБІЛЬНИЙ ІНТЕРНЕТ

Поки не виконані наступні два системні кроки, клієнт з іншої мережі не під’єднається:

1. На роутері: TCP 45873 зовні → локальна IP-адреса серверного комп’ютера, порт 8788.
2. У брандмауері Windows: дозволити вхідний TCP на порт 8788 для серверної програми.

Після цього:
• серверна програма має бути запущена;
• ноутбук перемкнути з домашнього Wi-Fi на мобільну точку доступу;
• запустити Price Monitor Remote Test;
• ввести виданий код активації.

Ці два системні кроки треба робити разом із власником. Інсталятор їх не змінює автоматично.

ВАЖЛИВІ ОБМЕЖЕННЯ ДОМАШНЬОГО ТЕСТУ

• Якщо провайдер змінив публічну IP-адресу, клієнт за старою адресою не знайде сервер.
• Якщо роутер перебуває за CGNAT, звичайна переадресація порту не допоможе.
• Прямий HTTP не шифрує трафік. Це експеримент, а не фінальна комерційна схема.
• Для продажів сервер переноситься в хмару з HTTPS; панель і клієнтська логіка вже розділені для такого переїзду.
