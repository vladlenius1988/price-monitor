PRICE MONITOR 4.22.2 — ПЕРЕВІРКА АКТИВАЦІЇ

1. Встановіть Price Monitor Cloud Admin Setup 4.22.2.exe на комп'ютері власника.
2. У вже створеної активної ліцензії натисніть «Новий код».
3. Підтвердьте перевипуск. Старий код після цього більше не працює.
4. Переконайтеся, що біля коду написано «Скопійовано».
5. Передайте тільки цей код на комп'ютер із Price Monitor Cloud Test.
6. Вставте код у поле активації та натисніть «Активувати».
7. Оновіть Cloud Admin: у ліцензії має з'явитися пристрій і версія клієнта.

Якщо автоматичне копіювання не спрацювало, код можна виділити у зеленому блоці
та скопіювати вручну. Останні п'ять символів повинні збігатися з підказкою
«код ···XXXXX» у рядку ліцензії.

Cloud Test 4.22.1 і 4.22.2 сумісні з цим сервером. Для виправлення саме видачі
коду достатньо оновити Cloud Admin; клієнт можна оновити окремо.
