PRICE MONITOR 4.23.0 — ШВИДКИЙ СТАРТ

ДЛЯ ВЛАСНИКА

1. Відкрийте Price Monitor Cloud Admin 4.23.0.
2. У блоці «Додати нового клієнта» вкажіть організацію, строк, кількість
   комп'ютерів і доступні магазини.
3. Натисніть «Створити клієнта й отримати код».
4. Натисніть «Скопіювати код та інструкцію» і надішліть готове повідомлення
   клієнту.
5. Після активації пристрій з'явиться в картці клієнта. Там буде видно назву
   комп'ютера, короткий код, версію та час останнього зв'язку.

ДЛЯ КЛІЄНТА

1. Встановіть Price Monitor Cloud Test 4.23.0.
2. Отримайте у власника довгий код формату PM-XXXXX-XXXXX-…
3. Вставте його у поле «Код активації» та натисніть «Активувати».
4. Дочекайтеся повідомлення, що код прийнято, пристрій прив'язано, а ліцензію
   активовано.

Короткий код на кшталт 4B16-2068-BB0D-C864 — це код пристрою. Його не треба
вводити в поле активації.

ОНОВЛЕННЯ ВЖЕ АКТИВОВАНОГО КЛІЄНТА

Cloud Test 4.23.0 можна встановити поверх Cloud Test 4.22.2. Активована
ліцензія та локальні дані залишаться у профілі Windows; повторний код не
потрібен.

РЕЗЕРВНИЙ ВАРІАНТ

Файловий запит та імпорт офлайн-ліцензії знаходяться у блоці «Резервна
активація без сервера». Використовуйте їх лише за вказівкою власника.
